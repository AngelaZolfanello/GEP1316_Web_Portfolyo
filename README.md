# GEP1316 Web Portfolyosu

Bu klasör, GEP1316 Kodlama Okuryazarlığı dersi için hazırlanan kişisel web portfolyosudur. Tasarım, 3D sanat portfolyosu için koyu lacivert zemin ve mor-turkuaz vurgular kullanır. Sayfalar telefon, tablet ve masaüstü ekranlarına uyumludur.

## Dosyalar ve klasörler

- `index.html`: Ana sayfa.
- `hakkimda.html`: Hakkımda sayfası.
- `projeler.html`: Projeler sayfası.
- `iletisim.html`: İletişim sayfası.
- `style.css`: Sayfaların ortak renklerini, yerleşimini, bileşenlerini ve duyarlı görünümünü tanımlar.
- `script.js`: İleride JavaScript eklemek için ayrılmıştır; şu an etkileşim içermez.
- `images/`: Görselleri saklamak için klasör.

Proje kartları ve iletişim formu şimdilik içerik/gönderim işlevi eklenmesi için taslak olarak bırakılmıştır.
